# IL VUOTO · La Stanza

La pagina-compagna dei libri *IL VUOTO* di Antonio Flamini: la Stanza, il Test del Silenzio, la domanda di Oggi, Cancella, i Giochi e Passa.

Sito: https://antonioflamini.github.io/ilvuoto/

- `index.html` — tutta la pagina (testi e codice)
- `og.png` — anteprima quando il link viene condiviso
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png`, `icon.svg` — icona per "Mettila nella Home"

Fuori da Claude la Stanza risponde con la "voce a frammenti" (frasi scritte prima, nessun dato inviato). Il libro: https://www.amazon.it/dp/B0H2P38RJP
